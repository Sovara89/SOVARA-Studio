# TASK-009 — VK VIDEO PUBLISHER

Requirements mirror TASK-008 where VK APIs allow:

- real user authorization/account model;
- secure credential lifecycle;
- large-video-safe upload;
- no full video buffering in RAM;
- metadata;
- persisted external id/url/progress;
- transient/permanent error handling;
- idempotent/reconciliation behavior as far as VK API permits.
